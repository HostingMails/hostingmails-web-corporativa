# HostingMails

Landing corporativa de **HostingMails.com**, servicio de hosting de correo electrónico
profesional para empresas: buzones con dominio propio, alias, reenvíos, almacenamiento,
protección antispam y webmail.

## Stack

- Vue 3 · Composition API con `<script setup lang="ts">`
- TypeScript
- Vite
- CSS moderno con nesting nativo y variables globales

Sin frameworks de CSS ni librerías de componentes.

## Puesta en marcha

```bash
npm install
npm run dev        # servidor de desarrollo
npm run build      # comprobación de tipos + build de producción
npm run preview    # sirve el build
npm run typecheck  # solo comprobación de tipos
```
